# Lista de tarefas

Aplicação para organizar tarefas pendentes e concluídas, desenvolvida com Angular, Angular Material e SCSS. Utiliza JSON Server como API local.

## Executar

Com Node.js e npm instalados:

```bash
npm install
npm start
```

- Aplicação: [http://localhost:4200](http://localhost:4200)
- API: [http://localhost:3000/tarefas](http://localhost:3000/tarefas)

A cada `npm start`, o banco local é restaurado a partir de `banco.base.json`, descartando os dados da execução anterior.

## Build

```bash
npm run build
```

Os arquivos gerados ficam em `dist/`.
